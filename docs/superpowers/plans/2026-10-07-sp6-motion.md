# SP6 Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the eight motivated interactions the audited spec keeps:

- D05 card → case morph
- D11 confirmation
- D03 Home signature
- D06 theme reveal
- D07 language swap
- D08 mobile menu
- D04 Home cards entrance
- D15 404 drawing

They use native View Transitions, CSS and a few small vanilla scripts, with zero dependencies.

**Architecture:** `@view-transition { navigation: auto }` plus a short root crossfade and `view-transition-name: sheet-{id}` give the page transitions without ClientRouter. Every navigation stays a normal page load, so no script rewiring is needed. Global rules go in a new `src/styles/transitions.css`, because `motion.css` and the tokens stay byte-identical. Each component owns its own motion in scoped CSS, and a tiny script where state is involved (theme, language, menu, reveal). Head flags (`html.js`, `html.sig`) are set by the existing inline head script before first paint.

**Tech Stack:** Astro 7 (static + one Vercel function), plain CSS with the handoff motion tokens, vanilla TypeScript, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-07-sp6-motion-design.md`

## Global Constraints

- **Dependencies:** npm only, no new dependency (no `motion`, no ClientRouter).
- **`src/styles/tokens/*.css` and `src/styles/motion.css` are never edited.** `tests/tokens.spec.ts` enforces it. Overrides go in `src/styles/transitions.css`, imported after `motion.css`.
- **Animated properties:** only transform, opacity, clip-path and stroke-dashoffset.
- **Never animate:** focus rings, nav jumps, content already revealed, the status dot, prices or spec values, loops, or elevation on hover.
- **LCP:** never delay it. The hero h1, the case header and the sent-page panel never start at `opacity: 0`; their entrances are transform-only.
- **Reduced motion:** leaves only fades, or nothing. JS off: all content stays visible.
- **Token values used verbatim:**
  - `--dur-fade` 150ms
  - `--dur-enter` 350ms
  - `--dur-sheet` 450ms
  - `--dur-draw` 600ms
  - `--stagger` 60ms
  - `--rise` 12px
  - `--ease-out`, `--ease-in-out`, `--ease-draw`
- **Spec-only values:**
  - frame side delays 0/130/260/390ms
  - ruler stagger 30ms from 520ms
  - check draw 400ms after a 200ms delay
  - 404 second diagonal 120ms later
  - menu 250ms in / 200ms out
- **Process:**
  - local tests: `npx playwright test --workers=1`
  - commits follow `.gitmessage` with scope `motion` (`docs` for docs)
  - working dir: `.worktrees/sp6-motion`

## Review Focus

1. **Rapid double click on the theme toggle while a transition runs.** The final `data-theme` must equal the stored `localStorage.theme`, and `html.theme-reveal` must not stick. Test in Task 3.
2. **Reduced motion plus theme toggle.** The theme still flips and `theme-reveal` is never added. Test in Task 3.
3. **Mobile menu: a viewport change to desktop mid-animation, or a double tap.** It must end in a consistent state: `aria-expanded="false"` with the panel hidden. Tests in Task 6.
4. **Language swap from the very top of the page, or with nothing stored.** The twin opens at the top and no stale state leaks into a later navigation. Test in Task 4.
5. **A case page lists the "next" card next to its own header.** All `view-transition-name`s stay unique there. If they weren't, Chrome would skip the transition entirely. Test in Task 2.

- [ ] **Step 2: Replace the `<script>` in `ThemeToggle.astro`:**

```ts
<script>
  const root = document.documentElement;
  const reduce = matchMedia('(prefers-reduced-motion: reduce)');
  const token = (name: string) => getComputedStyle(root).getPropertyValue(name).trim();

  const setTheme = (next: string) => {
    root.dataset.theme = next;
    try {
      localStorage.setItem('theme', next);
    } catch {
      // storage blocked: the choice lasts for this page only
    }
  };

  for (const btn of document.querySelectorAll<HTMLButtonElement>('.theme-toggle')) {
    btn.addEventListener('click', () => {
      const current =
        root.dataset.theme ??
        (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
      const next = current === 'dark' ? 'light' : 'dark';
      if (!document.startViewTransition) return setTheme(next);
      // Reduced motion keeps the plain root crossfade.
      if (reduce.matches) return void document.startViewTransition(() => setTheme(next));

      // D06: circular reveal from the toggle's centre to the farthest viewport corner.
      const r = btn.getBoundingClientRect();
      const x = r.left + r.width / 2;
      const y = r.top + r.height / 2;
      const radius = Math.hypot(Math.max(x, innerWidth - x), Math.max(y, innerHeight - y));
      root.classList.add('theme-reveal');
      const vt = document.startViewTransition(() => setTheme(next));
      vt.ready
        .then(() =>
          root.animate(
            { clipPath: [`circle(0px at ${x}px ${y}px)`, `circle(${radius}px at ${x}px ${y}px)`] },
            {
              duration: parseFloat(token('--dur-sheet')),
              easing: token('--ease-in-out'),
              pseudoElement: '::view-transition-new(root)',
            },
          ),
        )
        .catch(() => {});
      vt.finished.finally(() => root.classList.remove('theme-reveal'));
    });
  }
</script>
```

If `npm run check` reports `startViewTransition` as always-defined, compare against `'startViewTransition' in document` instead. Keep the behaviour identical.

- [ ] **Step 2: Replace the `<script>` in `LangSwitch.astro`:**

```ts
<script>
  // D07: switching language keeps the reading position. The twin pages share their section
  // structure but not their text length, so the position is "section index + offset into it".
  const KEY = 'fm-lang-swap';
  const blocks = () => [...document.querySelectorAll<HTMLElement>('main section')];

  for (const a of document.querySelectorAll<HTMLAnchorElement>('.lang-switch a[data-lang]')) {
    a.addEventListener('click', () => {
      try {
        localStorage.setItem('lang', a.dataset.lang ?? 'en');
      } catch {
        // storage blocked: the link still navigates
      }
      let index = -1;
      let offset = 0;
      blocks().forEach((el, i) => {
        const r = el.getBoundingClientRect();
        // the last match is the innermost section crossing the viewport top
        if (r.top <= 0 && r.bottom > 0) {
          index = i;
          offset = -r.top;
        }
      });
      try {
        if (index >= 0) sessionStorage.setItem(KEY, JSON.stringify({ index, offset }));
      } catch {
        // storage blocked: the twin opens at the top
      }
    });
  }

  try {
    const saved = sessionStorage.getItem(KEY);
    if (saved) {
      sessionStorage.removeItem(KEY);
      const { index, offset } = JSON.parse(saved) as { index: number; offset: number };
      const el = blocks()[index];
      if (el) scrollTo(0, el.getBoundingClientRect().top + scrollY + Math.min(offset, el.offsetHeight - 1));
    }
  } catch {
    // storage blocked or bad value: stay at the top
  }
</script>
```

The restore runs when the module executes (the DOM is parsed). This replaces the spec's `pagereveal` hook, which may fire before or after module scripts; ledger it as a ruling.

```ts
const reduce = window.matchMedia('(prefers-reduced-motion: reduce)');
const token = (name: string) =>
  getComputedStyle(document.documentElement).getPropertyValue(name).trim();

for (const btn of document.querySelectorAll<HTMLButtonElement>('.menu-btn')) {
  const panel = document.getElementById(btn.getAttribute('aria-controls') ?? '');
  if (!panel) continue;
  let running: Animation | null = null;
  const isOpen = () => btn.getAttribute('aria-expanded') === 'true';

  // D08: clip from the top, 250ms in / 200ms out (opacity only under reduced motion).
  // A new open/close cancels the running one, so fast taps always end consistent.
  const set = (open: boolean) => {
    if (open === isOpen() && open === !panel.hidden) return;
    btn.setAttribute('aria-expanded', String(open));
    btn.textContent = (open ? btn.dataset.open : btn.dataset.closed) ?? '';
    running?.cancel();
    const frames = reduce.matches
      ? { opacity: [0, 1] }
      : { clipPath: ['inset(0 0 100% 0)', 'inset(0)'] };
    if (open) {
      panel.hidden = false;
      running = panel.animate(frames, { duration: 250, easing: token('--ease-out') });
      return;
    }
    const closing = panel.animate(frames, {
      duration: 200,
      easing: token('--ease-out'),
      direction: 'reverse',
    });
    closing.onfinish = () => (panel.hidden = true);
    running = closing;
  };
  btn.addEventListener('click', () => set(!isOpen()));
  panel.addEventListener('click', (e) => {
    if ((e.target as Element).closest('a')) set(false);
  });
  document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape' && isOpen()) {
      set(false);
      btn.focus();
    }
  });
  desktop.addEventListener('change', (e) => {
    if (e.matches) {
      running?.cancel();
      btn.setAttribute('aria-expanded', 'false');
      btn.textContent = btn.dataset.closed ?? '';
      panel.hidden = true; // no animation when the layout switches to desktop
    }
  });
}
```

Keep the existing `const desktop = window.matchMedia('(min-width: 1200px)');` line above the loop.

The early return makes `set(false)` on an already-closed menu a no-op. That guard is why a stray desktop change or Escape can't flip a closed menu.

```ts
// D04: the Home case cards rise in once, staggered (--i), when their grid scrolls into view.
// motion.css hides [data-reveal] only under html.js, so without JS the cards are simply there.
const groups = [...document.querySelectorAll<HTMLElement>('[data-reveal-group]')];

const show = (group: Element, instant = false) => {
  for (const el of group.querySelectorAll<HTMLElement>('[data-reveal]')) {
    if (instant) el.style.transition = 'none';
    el.classList.add('is-in');
  }
};
// Never leave content hidden behind an anchor jump or on paper.
const showAll = () => groups.forEach((g) => show(g, true));
addEventListener('hashchange', showAll);
addEventListener('beforeprint', showAll);

const io = new IntersectionObserver(
  (entries) => {
    for (const e of entries) {
      if (!e.isIntersecting) continue;
      show(e.target);
      io.unobserve(e.target);
    }
  },
  { rootMargin: '0px 0px -10% 0px' },
);
for (const g of groups) {
  // Already on screen at load (or reached via #hash): show it without a fade.
  if (location.hash || g.getBoundingClientRect().top < innerHeight) show(g, true);
  else io.observe(g);
}
```
