# SP3 Offer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Services (P03) and Pricing (P04) from `pricing` and `faq` content collections. The components are ported value for value from the handoff.

**Architecture:**

- **Data:** package files (`src/content/pricing/{en,es}/*.md`, frontmatter only) are the single source for prices, the Services sheets and the comparison table. FAQ JSON is loaded by an inline loader that tags each entry with its language.
- **Logic:** pure helpers in `src/lib/offer.ts` format prices and filter the FAQ.
- **Rendering:** presentational components with scoped CSS on semantic tokens. Two page components are rendered by the existing route stubs.

**Tech Stack:** Astro 7 content collections, plain CSS, native `<details>`, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-07-sp3-offer-design.md`

## Global Constraints

- npm only; no new dependencies.
- Semantic tokens only; radius 0; no shadows; the hatch is the only gradient; glyphs only (→ — ✓ +).
- Values come from `docs/handoff/design/Services.dc.html` and `Pricing.dc.html`. Copy is verbatim from their `COPY` objects.
- Tokens untouched (`tests/tokens.spec.ts`).
- Hover only under `@media (hover: hover) and (pointer: fine)`. Transitions are disabled under `prefers-reduced-motion: reduce`.
- Local tests: `npx playwright test --workers=1`.
- Commits follow `.gitmessage` (scopes `content`, `ui`, `pages`, `docs`).
- Working dir `.worktrees/sp3-offer`. Before removing the worktree, leave it (`cd` to the root).

## Review Focus

1. **A price edited in one language only:** EN and ES diverge. Expected: both files exist per package, and a test asserts equal `from`/`billing` per `id` across languages (Task 3).
2. **Compare table on phones:** the 620px table must scroll inside its region, never the page. Pinned by `overflow.spec.ts` (Services/Pricing are in `ROUTES`) and the scroller test (Task 6).
3. **FAQ without JS:** native `<details>` must toggle and the first must be open. Pinned (Task 6).
4. **FAQ JSON-LD:** malformed JSON breaks rich results silently. Pinned by parsing it in the test (Task 6).
5. **`both` FAQ items:** must appear on both pages without duplicates. Pinned by the `faqFor` unit test with a synthetic `both` item (Task 2).

- [ ] **Step 3: `src/lib/offer.ts`**

```ts
import type { Lang } from '../i18n/routes';
import { ui } from '../i18n/ui';

type Billing = 'project' | 'month';

/** "$4,500" — the design uses US formatting in both languages. */
export const formatUsd = (n: number) => '$' + new Intl.NumberFormat('en-US').format(n);

export const unitLabel = (billing: Billing, lang: Lang) => ui[lang].offer.units[billing];

/** Services FROM cell: "$900", "$2,800 / mo", "$2,800 / mes". */
export const priceShort = (p: { from: number; billing: Billing }, lang: Lang) =>
  p.billing === 'month'
    ? `${formatUsd(p.from)} / ${ui[lang].offer.units.monthShort}`
    : formatUsd(p.from);

interface FaqLike {
  data: { lang: Lang; page: 'pricing' | 'services' | 'both'; order: number };
}

/** FAQ items for a page: its own plus the shared ones, in that language, by `order`. */
export const faqFor = <T extends FaqLike>(all: T[], page: 'pricing' | 'services', lang: Lang) =>
  all
    .filter((e) => e.data.lang === lang && (e.data.page === page || e.data.page === 'both'))
    .sort((a, b) => a.data.order - b.data.order);

export const byOrder = <T extends { data: { order: number } }>(list: T[]) =>
  [...list].sort((a, b) => a.data.order - b.data.order);
```

import { test, expect } from '@playwright/test';
import { readFileSync, readdirSync } from 'node:fs';

const fm = (path: string) => {
  const text = readFileSync(path, 'utf8');
  const get = (k: string) => text.match(new RegExp(`^${k}: (.+)$`, 'm'))?.[1].trim();
  return { id: get('id'), from: get('from'), billing: get('billing'), featured: get('featured') };
};

test('every package exists in both languages with the same id, price and billing', () => {
  const en = readdirSync('src/content/pricing/en').sort();
  const es = readdirSync('src/content/pricing/es').sort();
  expect(es).toEqual(en);
  expect(en).toHaveLength(3);
  for (const file of en) {
    expect(fm(`src/content/pricing/es/${file}`), file).toEqual(
      fm(`src/content/pricing/en/${file}`),

  }
});
