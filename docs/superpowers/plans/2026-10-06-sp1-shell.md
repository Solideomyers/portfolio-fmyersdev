# SP1 Shell & i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A navigable, empty site in EN/ES and light/dark: route map with translated slugs, base layout, SiteNav/SiteFooter, LangSwitch/ThemeToggle, root language redirect, static bilingual 404.

**Architecture:** One route map (`src/i18n/routes.ts`) is the only place URLs live. Thin per-language pages render a shared `Stub` inside `Base.astro`. Nav, LangSwitch, hreflang and 404 read the map. Theme and language preferences sit in `localStorage`, applied by tiny inline scripts before paint. Everything works without JS except the menu toggle (it degrades to an open menu).

**Tech Stack:** Astro 7 (static), TypeScript strict, plain CSS with handoff tokens, vanilla TS, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-06-sp1-shell-design.md`

## Global Constraints

- npm only. No new dependencies in SP1.
- No React/Tailwind/shadcn/icon libraries. Glyphs only (◐ ↗ → ·).
- Components read semantic tokens only (`--bg`, `--text`, `--accent`, `--invert-bg`, …). Radius 0, no shadows.
- `src/styles/tokens/*.css` and `src/styles/motion.css` are never edited (`tests/tokens.spec.ts`).
- Copy is verbatim from the handoff `COPY` objects (listed in the spec).
- Breakpoints: desktop ≥ 1200px, tablet 640–1199px, mobile < 640px.
- Touch targets in the menu ≥ 44px; menu rows ≥ 52px.
- Commits follow `.gitmessage`; scopes from `scripts/scopes.cjs`. Commit/push only with the user's approval (granted per SP at execution start).
- Shell: Git Bash. Working dir: `.worktrees/sp1-shell`. Tests run on port 4329 with no server reuse (SP0 config).

## Review Focus

1. **Stored theme opposite to OS:** stored `light` with OS `dark`. Expected: light page _and_ light wordmark. Pinned in `theme.spec.ts` (Task 3).
2. **Trailing-slash URLs** (`/es/servicios/`): Expected: same `aria-current`, same LangSwitch target. Pinned in `routes.spec.ts` (Task 3) and the unit test (Task 2).
3. **Blocked localStorage** (privacy mode throws on access): Expected: pages render, toggle still flips the theme for the session. Pinned in `theme.spec.ts` (Task 3).
4. **Menu open, then resize to desktop:** Expected: menu closes and MENU state resets. Pinned in `nav.spec.ts` (Task 3).
5. **Garbage stored language** (`lang = 'fr'`): Expected: ignored, browser language used. Pinned in `redirect.spec.ts` (Task 4).

```ts
export type Lang = 'en' | 'es';
export const LANGS: readonly Lang[] = ['en', 'es'];

// The only place URLs are written. Grows per sub-project (contact/sent in SP4, notes in SP6).
export const ROUTES = {
  home: { en: '/en', es: '/es' },
  services: { en: '/en/services', es: '/es/servicios' },
  work: { en: '/en/work', es: '/es/proyectos' },
  about: { en: '/en/about', es: '/es/sobre-mi' },
  pricing: { en: '/en/pricing', es: '/es/precios' },
  contact: { en: '/en/contact', es: '/es/contacto' },
  privacy: { en: '/en/privacy', es: '/es/privacidad' },
} as const satisfies Record<string, Record<Lang, string>>;

export type RouteKey = keyof typeof ROUTES;

export const NAV = [
  'services',
  'work',
  'about',
  'pricing',
  'contact',
] as const satisfies readonly RouteKey[];
export type NavKey = (typeof NAV)[number];

export const path = (key: RouteKey, lang: Lang): string => ROUTES[key][lang];
export const other = (lang: Lang): Lang => (lang === 'en' ? 'es' : 'en');
export const langOf = (pathname: string): Lang =>
  pathname === '/es' || pathname.startsWith('/es/') ? 'es' : 'en';

const trim = (p: string) => (p.length > 1 ? p.replace(/\/+$/, '') : p);

export function routeKeyOf(pathname: string): RouteKey | undefined {
  const p = trim(pathname);
  return (Object.keys(ROUTES) as RouteKey[]).find((k) => ROUTES[k].en === p || ROUTES[k].es === p);
}

/** This page in the other language. `alternate` overrides: a URL, or null when no translation exists. */
export function alternateOf(pathname: string, alternate?: string | null): string | null {
  if (alternate !== undefined) return alternate;
  const target = other(langOf(trim(pathname)));
  const key = routeKeyOf(pathname);
  return key ? ROUTES[key][target] : ROUTES.home[target];
}
```
