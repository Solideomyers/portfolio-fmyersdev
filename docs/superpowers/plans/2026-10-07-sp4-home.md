# SP4 Home & About Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home (P01), About (P06) and Privacy (P11), ported value for value from the handoff, reusing SP2/SP3 components and data.

**Architecture:**

- **Copy:** in `ui[lang].home|about|privacy`.
- **Package teasers:** a new `teaser[]` field in the pricing files.
- **Privacy:** read from a new `pages` collection.
- **Helpers:** `src/lib/home.ts` holds availability and featured-case selection, unit-tested.
- **Components:** new ones are scoped-CSS ports. Existing ones gain variants: `SpecGrid` rows, `PackageCard` compact, `Prose` page.
- **Availability:** built statically, corrected by a tiny inline script when the visitor's clock is past the date.

**Tech Stack:** Astro 7 content collections, `astro:assets`, plain CSS, Playwright (with `page.clock`).

**Spec:** `docs/superpowers/specs/2026-10-07-sp4-home-design.md`

## Global Constraints

- npm only; no new dependencies.
- Semantic tokens only; radius 0 except the status dot; no shadows; the hatch is the only gradient; glyphs only.
- Values come from `Home.dc.html`, `About.dc.html` and `Privacy.dc.html`. Copy is verbatim from their `COPY` objects.
- Tokens untouched. Hover only on fine pointers. Transitions are off under reduced motion.
- Local tests: `npx playwright test --workers=1`.
- Commits follow `.gitmessage`.
- Working dir: `.worktrees/sp4-home`. `cd` out of it before removing it.

## Review Focus

1. **Availability around the boundary** (Oct 31 vs Nov 1, other time zones). Expected: dateless from Nov 1 UTC. Pinned by unit tests at both edges and the `page.clock` e2e (Tasks 2, 5).
2. **No JS.** Expected: the build-time sentence shows and nothing breaks. Pinned in Task 5.
3. **Home with 0, 1 or 4 featured cases.** Expected: hidden, 1, or capped at 3. Pinned by `featuredCases` unit tests (Task 2).
4. **Inverted contact block in dark mode.** Text and links must stay readable (invert tokens flip per theme). Pinned by a dark-mode colour assertion (Task 5).
5. **Heading order** on all three pages (h1 → h2 only). Pinned by the heading-order test (Tasks 5–7).

- [ ] **Step 3: `src/lib/home.ts`**

```ts
import type { Lang } from '../i18n/routes';
import { ui } from '../i18n/ui';

/**
 * Availability sentence from site.availableFrom ("YYYY-MM"). "Available from Nov 2026" means
 * from Nov 1 (UTC); from then on the dateless sentence shows.
 */
export function availability(from: string, now: Date, lang: Lang) {
  const m = /^(\d{4})-(\d{2})$/.exec(from);
  if (!m) throw new Error(`site.availableFrom must be YYYY-MM, got "${from}"`);
  const year = Number(m[1]);
  const month = Number(m[2]);
  const h = ui[lang].home;
  if (now.getTime() >= Date.UTC(year, month - 1, 1)) return { text: h.availableNow, dated: false };
  const mon = ui[lang].months[month - 1];
  const label = lang === 'es' ? mon.toLowerCase() : mon.charAt(0) + mon.slice(1).toLowerCase();
  return { text: h.available.replace('{date}', `${label} ${year}`), dated: true };
}

/** Home "Selected work": own-language, featured, non-draft cases by `order`, at most 3. */
export const featuredCases = <
  T extends { data: { lang: Lang; draft: boolean; featured: boolean; order: number } },
>(
  all: T[],
  lang: Lang,
) =>
  all
    .filter((e) => e.data.lang === lang && e.data.featured && !e.data.draft)
    .sort((a, b) => a.data.order - b.data.order)
    .slice(0, 3);
```
